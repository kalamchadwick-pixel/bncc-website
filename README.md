# BNCC Website

Landing page sederhana untuk BNCC, dibuat kolaboratif oleh tim 3 orang memakai alur Git & GitHub (branch, Pull Request, code review).

## Visualisasi

![Screenshot](screenshot.png)

Demo: https://kalamchadwick-pixel.github.io/bncc-website

## Tech Stack

- HTML5
- CSS3
- JavaScript (vanilla)
- Git & GitHub

## Fitur Utama

- Navbar dengan anchor link ke tiap section
- Hero section dengan tombol Join Us yang interaktif
- Dark mode / light mode toggle
- Card program yang responsif
- Footer dengan tahun otomatis
